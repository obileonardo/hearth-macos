# README showcase

`hearth-showcase.png` is composed illustrative artwork based on Hearth's existing device library. It introduces five device families at a readable size: Climate, Security, Speakers, Energy and Vehicles. The native artwork exports remain available in `devices.png` and `devices/`.

The composition uses a landscape frame, one active example per device, consistent captions, generous margins and restrained lighting. Generated with the built-in image-generation tool on 2026-10-14, then reviewed and refined to use the correct inverter design.

## Prompt used for the composition

> Use case: compositing / ads-marketing. Asset type: a polished landscape README introduction image for the existing native macOS smart-home app Hearth. Input image 1 is the edit target and source illustration library. Redesign its cluttered technical contact sheet into an intentional, spacious premium product illustration showcase. Preserve the recognizable illustrated devices and their existing satin white, black glass, fabric, subtle luminous details; do not invent a different illustration style or new branded products. Landscape approximately 16:9. OLED charcoal background, very restrained cool blue ambient lighting and warm ivory typography. Create five carefully spaced visual groups in a composed editorial layout, with generous outer margins and consistently sized captions: Climate (one larger wall AC with delicate visible airflow), Security (one outdoor bullet camera with round black lens and short mount, one small doorbell), Speakers (one Echo-style fabric sphere with blue base light, one smaller HomePod mini with blue top), Energy (one inverter and a smaller battery), Vehicles (one robot vacuum). Use only one active example of each object; remove all off-state duplicates, contact-sheet rows, tiny repeated thumbnails, badges and debugging size comparisons. Art must be crisp, isolated on the dark background with soft grounded contact shadows; no huge empty right half. Organize the groups using subtle spacious composition and soft fine separators rather than loud boxes. Category text exactly: 'Climate', 'Security', 'Speakers', 'Energy', 'Vehicles'. Include no other text, logo, simulated app screen, watermark, fake controls, marketing claim, decorative neon grid or bright gradients. Keep the same Hearth visual identity. Devices should feel substantial and curated, with a visually coherent hierarchy and harmonious balance at GitHub README display width 900 pixels.
